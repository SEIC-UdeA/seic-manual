# SEIC Manual

Repositorio oficial del **Manual de Organización del Semillero de Investigación en Ciberseguridad (SEIC)** de la Universidad de Antioquia.

Este repositorio contiene la documentación institucional que define la estructura organizacional, procesos, políticas, estándares y lineamientos de funcionamiento del semillero.

El objetivo de este manual es garantizar que todos los integrantes compartan una misma forma de trabajo, facilitando la continuidad del semillero, la incorporación de nuevos miembros y el desarrollo organizado de proyectos e iniciativas.

---

# Objetivos

- Centralizar la documentación institucional del semillero.
- Definir procesos y estándares de trabajo.
- Facilitar la incorporación de nuevos integrantes.
- Mantener un historial de cambios mediante control de versiones.
- Garantizar la continuidad del conocimiento y la organización del semillero.

# Uso del manual

Todo integrante del semillero, tanto actual como nuevo, deberá leer este manual para comprender la estructura, procesos, responsabilidades y herramientas utilizadas por SEIC.

El manual constituye la referencia oficial para la operación del semillero.

---

# Control de versiones

Las modificaciones al manual deberán realizarse mediante Pull Request y quedar registradas en el historial de cambios del repositorio.

La versión oficial del manual se identifica mediante versionado semántico.

Ejemplo:

- v1.0.0
- v1.1.0
- v1.1.1
- v2.0.0

---

# Cómo contribuir

Las contribuciones a este repositorio deberán seguir el proceso definido en el archivo `CONTRIBUTING.md`.

Toda modificación deberá estar justificada, revisada y aprobada antes de incorporarse a la versión oficial del manual.
